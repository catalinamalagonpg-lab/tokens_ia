Tokens de inteligencia artificial

Una guía para comprender cómo los modelos de IA procesan el lenguaje, por qué utilizan tokens y qué debemos tener en cuenta al integrar estas herramientas en un producto de software.

Presentado por:
Laura Valentina Reyes Zambrano
Laura Catalina Malagon
Cuarto semestre · Universidad de Cundinamarca

1. ¿Qué es un token?

Un token es una unidad de texto que un modelo de inteligencia artificial utiliza para representar y procesar la información. Puede corresponder a una palabra completa, una parte de una palabra, un signo de puntuación o incluso espacios y otros elementos, según el sistema de tokenización.

Idea clave: un token no equivale necesariamente a una palabra. Por eso, contar palabras no permite conocer con exactitud cuántos tokens tiene un texto.
🔤

Palabra completa

Algunas palabras frecuentes pueden representarse como un solo token.

🧩

Fragmento

Una palabra larga o poco frecuente puede dividirse en varias unidades.

✳️

Signos y símbolos

La puntuación, números y ciertos símbolos también pueden generar tokens.

2. ¿Cómo funcionan?

Antes de procesar una solicitud, el modelo convierte el texto en tokens mediante un proceso llamado tokenización. Después analiza la secuencia, calcula qué elementos son relevantes y genera una respuesta que también se convierte en tokens.

  1. Entrada: la persona escribe una instrucción o pregunta.
  2. Tokenización: el texto se divide en unidades que el modelo puede procesar.
  3. Procesamiento: el modelo utiliza el contexto disponible para interpretar la solicitud.
  4. Generación: produce una respuesta token por token.
  5. Salida: los tokens generados se convierten nuevamente en texto legible.
Importante: la forma exacta de dividir un texto depende del modelo y de su tokenizador. Dos modelos diferentes pueden contar los tokens de manera distinta.

3. ¿Por qué son importantes?

📏

Ventana de contexto

Los modelos tienen un límite de tokens que pueden considerar en una interacción. Ese límite puede incluir instrucciones, historial, documentos y respuesta.

💳

Costos de uso

En muchos servicios, el precio depende de los tokens de entrada y salida. Las tarifas varían según el proveedor y el modelo.

⚡

Rendimiento

La cantidad de información enviada puede influir en el tiempo de procesamiento y en el tamaño de la respuesta.

🧠

Calidad del contexto

Una solicitud clara y relevante ayuda a que el modelo reciba la información necesaria sin contenido innecesario.

4. Relación con Requerimientos de Software

Cuando un equipo decide incorporar IA generativa en un sistema, debe convertir esa idea en requisitos claros, verificables y medibles. Los tokens generan restricciones técnicas y económicas que deben contemplarse desde el análisis.

Tipo de requerimientoEjemplo relacionado con tokens¿Cómo verificarlo?
FuncionalEl sistema debe enviar la pregunta del usuario al modelo y mostrar la respuesta recibida.Realizar una prueba de envío y recepción de una consulta.
No funcional – rendimientoEl sistema debe responder dentro del tiempo definido para las consultas habituales.Medir tiempos con diferentes longitudes de entrada.
No funcional – capacidadEl sistema debe controlar la longitud de las instrucciones para respetar el límite de contexto del modelo.Probar entradas cercanas y superiores al límite configurado.
No funcional – costoEl sistema debe registrar o estimar el consumo de tokens por solicitud.Comparar el consumo registrado con el reporte del proveedor.
Seguridad y privacidadEl sistema no debe enviar datos personales innecesarios a un servicio externo de IA.Revisar los datos transmitidos y aplicar pruebas de privacidad.
En el análisis de requisitos: se deben definir límites de uso, comportamiento ante errores, manejo de información sensible, presupuesto, tiempos de respuesta y criterios de aceptación. No basta con escribir “el sistema tendrá inteligencia artificial”.

5. Ejemplo aplicado: asistente académico

Imaginemos una plataforma universitaria que utiliza IA para responder preguntas sobre una asignatura. Cada consulta y cada respuesta consumen tokens.

Necesidad del usuario

Consultar conceptos de una materia y recibir explicaciones sencillas.

Requisito funcional

El sistema permitirá escribir una pregunta y visualizar la respuesta generada por IA.

Restricción técnica

El sistema validará la longitud del contenido antes de enviarlo al modelo.

Prueba interactiva: estima el tamaño de un texto

Escribe una frase y observa una estimación didáctica. La regla usada aquí es aproximada: 1 token por cada 4 caracteres. No es un conteo real y puede variar según idioma y tokenizador.

Ejemplo de criterio de aceptación: “Dado que el usuario ingresa una consulta dentro del límite establecido, cuando la envía, entonces el sistema debe mostrar la respuesta del servicio de IA o informar claramente si se supera el límite o ocurre un error”.

6. Buenas prácticas para un proyecto de software

  • Escribir instrucciones concretas y evitar contexto que no aporte a la tarea.
  • Definir límites de caracteres o tokens y validar las entradas.
  • Controlar el consumo para evitar costos inesperados.
  • Informar al usuario cuando una solicitud sea demasiado extensa.
  • Proteger datos personales y revisar las políticas del proveedor de IA.
  • Probar el sistema con preguntas cortas, largas, ambiguas y casos de error.
  • Documentar el modelo, sus límites, costos y criterios de aceptación.

Conclusión

Los tokens son las unidades con las que los modelos de IA procesan el lenguaje. Comprenderlos permite estimar el tamaño de las solicitudes, administrar el contexto, controlar costos y diseñar mejores experiencias. Desde Requerimientos de Software, este conocimiento ayuda a especificar de forma clara las capacidades, restricciones, condiciones de seguridad y criterios de aceptación de un sistema que incorpora inteligencia artificial.

Glosario rápido

TokenizaciónProceso de dividir el texto en tokens.
Token de entradaUnidad procesada a partir de la información enviada al modelo.
Token de salidaUnidad generada como parte de la respuesta del modelo.
Ventana de contextoCantidad máxima de tokens que el modelo puede considerar en una interacción, según sus especificaciones.
TokenizadorMétodo o componente que realiza la división del texto.
